# 바르셀로나 여행 앱 — GitHub Pages 올리는 법

아이폰 홈 화면에 앱처럼 설치해서 쓰기 위한 파일입니다.
아래 순서대로 하면 10분 안에 끝납니다.

---

## 1단계 — 저장소 만들기

1. https://github.com 로그인 (계정이 없으면 먼저 가입)
2. 오른쪽 위 **+** → **New repository**
3. **Repository name**: `barcelona` (아무 이름이나 가능, 영문 소문자 권장)
4. **Public** 선택 ← 중요합니다. Private은 무료 플랜에서 Pages가 안 됩니다
5. 아래 **Create repository** 클릭

## 2단계 — 파일 올리기

1. 만들어진 저장소 화면에서 **uploading an existing file** 링크 클릭
   (안 보이면 **Add file** → **Upload files**)
2. 이 압축을 푼 폴더 안의 **파일 6개를 전부** 드래그해서 올립니다
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `apple-touch-icon.png`
   - `icon-192.png`
   - `icon-512.png`
   - (`README.md`는 올려도 되고 안 올려도 됩니다)

   ⚠️ **폴더째로 올리지 말고 파일만** 올려주세요. 폴더째 올리면 주소가
   `.../web/` 처럼 한 단계 깊어집니다.
3. 맨 아래 **Commit changes** 클릭

## 3단계 — Pages 켜기

1. 저장소 위쪽 **Settings** 탭
2. 왼쪽 메뉴에서 **Pages**
3. **Source**: `Deploy from a branch`
4. **Branch**: `main` / `/ (root)` 선택 후 **Save**
5. 1~2분 기다리면 같은 화면 위쪽에 주소가 뜹니다

   `https://<깃허브아이디>.github.io/barcelona/`

## 4단계 — 아이폰 홈 화면에 추가

1. **사파리**로 위 주소를 엽니다 (크롬 말고 사파리여야 합니다)
2. 아래 가운데 **공유 버튼**(⬆️) 누르기
3. 메뉴를 내려서 **홈 화면에 추가**
4. 이름을 `바르셀로나`로 두고 **추가**

끝입니다. 홈 화면에 지도 핀 아이콘이 생기고, 누르면 주소창 없이
전체화면으로 열립니다.

---

## 오프라인

처음 한 번 온라인에서 열면 앱이 스스로 저장됩니다.
그 뒤로는 비행기 모드에서도 열립니다.

- 온라인: 날짜별 페이지에 **실제 구글 지도 경로**가 뜹니다
- 오프라인: 같은 자리에 **동선 약도**가 뜨고, 화면 아래에 안내줄이 붙습니다
- 사진은 구글 서버에서 가져오므로 오프라인에서는 회색 칸이 됩니다.
  칸을 누르면 구글 지도로 연결됩니다

## 아내분과 같이 보기

주소만 보내주면 됩니다. 공개 저장소라 누구나 열 수 있고,
아내분도 사파리에서 똑같이 홈 화면에 추가하면 됩니다.

## 내용이 바뀌면

새 `index.html`을 받아서 저장소에 같은 이름으로 다시 올리면 됩니다.
(GitHub에서 기존 `index.html` 클릭 → 연필 아이콘 → 전체 선택 후 붙여넣기,
또는 Upload files로 덮어쓰기)

앱에서 바로 안 바뀌면 한 번 닫았다 다시 열어주세요.
서비스 워커가 새 버전을 받아옵니다.

---

## 안 될 때

**404가 뜬다** → 3단계에서 Branch가 `main`인지, 파일이 저장소 최상단에
있는지 확인하세요. `index.html`이 폴더 안에 들어가 있으면 안 됩니다.

**홈 화면에 추가가 안 보인다** → 사파리가 아닌 브라우저입니다. 사파리로 여세요.

**화면이 하얗게만 나온다** → 주소 끝에 `/`가 빠졌을 수 있습니다.
`https://아이디.github.io/barcelona/` 처럼 슬래시까지 붙여서 접속해보세요.
